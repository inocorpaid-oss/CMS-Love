# 💖 LovesUa — Українська дейтинг-платформа (Dating Application)

Сучасний, швидкий та безпечний веб-сервіс онлайн-знайомств, створений на базі екосистеми **Laravel 12**, **Tailwind CSS**, **Alpine.js** та **Chart.js**.

---

## 🌟 Основні можливості

- **💘 Tinder-подібні Знайомства (Encounters / Свайпи)**: картки анкет, лайки, дізлайки, суперлайки, анімація взаємних збігів (Match modal).
- **📍 Пошук поблизу (Nearby)**: геолокаційний пошук користувачів з розрахунком точної дистанції у кілометрах, фільтри за віком, статтю та містом.
- **💬 Онлайн Чат та WebRTC Відеодзвінки**: миттєві текстові повідомлення, стікери, віртуальні подарунки та P2P аудіо/відеодзвінки через WebRTC.
- **📸 Фото та Медіа з автокомпресією**: багатопотокове завантаження, оптимізація розміру, конвертація у WebP, прев'ю та модерація фотографій.
- **💰 Монетизація та Крамниця (Shop)**: внутрішні монети, купівля VIP-статусу, підняття анкети в ТОП, режим Інкогніто, перегляд гостей профілю, P2P банківські оплати за реквізитами з перевіркою квитанцій.
- **🛡️ Безпека та Приватність**: чорний список (Block), скарги на порушників (Report), двостороннє приховування контенту, 90-денне безпечне заморожування анкет (Grace Window).
- **📱 Авторизація**:
  - Вхід через Google OAuth та Apple Sign-In.
  - Безкоштовна телефонна верифікація через Telegram Bot OTP.
  - SMS-шлюзи TurboSMS / AlphaSMS / Twilio.
- **👑 Повнофункціональна Панель Адміністратора (`/admin`)**:
  - Дашборд з інтерактивними графіками Chart.js (реєстрації, виручка, пікові години навантаження).
  - Моніторинг RAM, диска та системних ресурсів сервера.
  - Модерація користувачів, фотографій та скарг.
  - Керування пакетами оплат (монет та VIP).
  - Редактор тем та візуального стилю.
  - Email-маркетинг, розсилки та шаблони листів.
  - Автоматична генерація `sitemap.xml`.

## 🚀 Встановлення та розгортання

Детальний покроковий посібник зі встановлення на будь-який тип хостингу або VPS дивіться у файлі:  
👉 **[INSTALL.md](INSTALL.md)**

### Швидкий старт (Локально / SSH):
```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

### Веб-майстер встановлення:
Відкрийте у браузері: `https://ваш-домен.com/install`

---

## 🛠️ Виробничі команди (Production Maintenance)

- **Кешування конфігурацій та маршрутів:**
  ```bash
  php artisan config:cache
  php artisan route:cache
  php artisan view:cache
  php artisan event:cache
  ```
- **Очищення кешу:**
  ```bash
  php artisan optimize:clear
  ```
- **Cron (Розклад завдань):**
  ```bash
  * * * * * cd /шлях/до/сайту && php artisan schedule:run >> /dev/null 2>&1
  ```

## 🔒 Безпека та права на папки

Веб-сервер повинен мати права запису у каталоги:
- `storage/`
- `bootstrap/cache/`

Для Linux / Nginx:
```bash
sudo chown -R www-data:www-data storage bootstrap/cache
sudo chmod -R 775 storage bootstrap/cache
```
