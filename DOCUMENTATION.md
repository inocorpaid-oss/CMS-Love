# 📚 LovesUa — Технічна документація проекту

Повна документація архітектури, структури бази даних, функціоналу користувача та адміністратора, ролей, API та налаштування сервера.

---

## 1. 📌 Огляд проекту

**LovesUa** — це сучасна високопродуктивна дейтинг-платформа, розроблена для ринку України та міжнародного використання. Проект поєднує класичну механіку свайпів (Tinder-подібні знайомства), точний геолокаційний пошук користувачів поблизу (Nearby), чат у реальному часі з підтримкою стікерів та віртуальних 3D-подарунків, аудіо/відеодзвінки WebRTC, розгалужену систему монетизації (VIP-підписки, монети, суперлайки, бусти, P2P банківські оплати), а також інтерактивну панель адміністратора для повної модерації контенту.

## 6. 👥 Ролі та права доступу

Система підтримує багаторівневу модель прав (`role` та `permissions`):

1. **`user` (Звичайний користувач)**:
   - Доступ до свайпів (з обмеженням кількості безкоштовних лайків на добу).
   - Чат та переписка з користувачами при наявності взаємного збігу.
   - Пошук за базовими фільтрами у Nearby.
2. **`vip` (VIP-користувач)**:
   - Необмежені лайки та щоденні безкоштовні суперлайки.
   - Безкоштовне використання режиму «Інкогніто».
   - Перегляд гостей свого профілю без сплати монет.
   - Додаткові розширені фільтри пошуку та пріоритет у стрічці анкет.
   - Золота рамка та бейдж VIP у профілі.
3. **`moderator` (Модератор)**:
   - Доступ до панелі модерації фотографій (`/admin/photos`).
   - Перевірка та обробка скарг на користувачів (`/admin/reports`).
   - Перевірка заявок на селфі-верифікацію (`/admin/verifications`).
   - Не має доступу до фінансових операцій, налаштувань сайту та редактора коду.
4. **`admin` (Головний адміністратор / Власник)**:
   - Повний необмежений доступ до всіх розділів системи, фінансів, налаштувань, бази даних, зміни тарифів та видалення акаунтів.

## 7. 🔌 API та AJAX Endpoints

Платформа використовує гібридну архітектуру Blade + оптимізовані JSON API endpoints:

### Геолокація та Пошук:
- `POST /api/geo/update-location` — оновлення координат користувача за GPS браузера.
- `GET /api/geo/locate-ip` — визначення приблизного міста за IP-адресою при відхиленні GPS.

### Свайпи та Механіка знайомств:
- `POST /swipe` — надсилання реакції (параметри: `target_id`, `type`: like/dislike/superlike). Повертає JSON із статусом збігу (`is_match: true/false`).
- `POST /swipe/rewind` — скасування останнього свайпу назад (для VIP або за монети).

### Чат та Сигналізація WebRTC:
- `POST /messages/{conversation}` — відправка повідомлення в активний чат.
- `GET /chat/{conversation}/poll` — опитування нових повідомлень (long-polling фолбек).
- `POST /chat/{conversation}/typing` — статус «співрозмовник друкує...».
- `POST /chat/call/signal` — обмін WebRTC SDP оферами та ICE-кандидатами для відеодзвінка.

### Медіа та Профіль:
- `POST /profile/photos` — завантаження фотографії з автоматичною WebP конвертацією.
- `DELETE /profile/photos/{photo}` — видалення фотографії.
- `PATCH /profile/photos/{photo}/primary` — встановлення фотографії як головного аватара.
- `POST /profile/incognito/toggle` — увімкнення/вимкнення режиму приховування.
- `GET /api/profile/deletion-status` — статус 90-денного періоду заморожування акаунта.

### Крамниця та Промокоди:
- `POST /promo/redeem` — активація промокоду.
- `POST /visitors/{visitor}/unlock` — розблокування картки гостя за монети.
- `POST /stories/{story}/view` — фіксація перегляду історії.

## 8. ⏱️ Налаштування Cron та Queues (Черг)

### 1. Налаштування Cron (Планувальник завдань Laravel)
Для роботи регламентних функцій (очищення старих історій через 24 години, перевірка терміну VIP-підписок, видалення анкет після 90 днів деактивації) додайте запис у Cron (`crontab -e`):

```bash
* * * * * cd /var/www/lovesua && php artisan schedule:run >> /dev/null 2>&1
```

### 2. Налаштування Черг (Queues)
Якщо у файлі `.env` встановлено `QUEUE_CONNECTION=database` або `QUEUE_CONNECTION=redis`, листи та важкі повідомлення обробляються у фоні.

Команда для запуску обробника черги:
```bash
php artisan queue:work --sleep=3 --tries=3 --max-time=3600
```

Для продакшн сервера налаштуйте демон **Supervisor** (детальний конфіг описано в `INSTALL.md`).

## 9. 🛠️ Часті проблеми та їх вирішення (Troubleshooting)

### 1. Помилка 500 або "Internal Server Error"
- **Причина:** Немає прав на запис у папку `storage` або відсутній файл `.env`.
- **Рішення:**
  ```bash
  chmod -R 775 storage bootstrap/cache
  chown -R www-data:www-data storage bootstrap/cache
  ```

### 2. Фотографії не відображаються після завантаження (404 на `/storage/...`)
- **Причина:** Відсутнє символічне посилання з `public/storage` на `storage/app/public`.
- **Рішення:**
  ```bash
  php artisan storage:link
  ```
  *(Якщо на хостингу заборонено symlink, перевірте наявність файлу `.htaccess` у папці `public`)*.

### 3. "The page has expired due to inactivity" (Помилка 419 Page Expired)
- **Причина:** Невідповідність `APP_URL` або домену сесій у `.env`.
- **Рішення:** Вкажіть точний URL вашого сайту в `.env` (наприклад, `APP_URL=https://ваш-домен.com`) та очистіть кеш:
  ```bash
  php artisan config:clear
  php artisan optimize:clear
  ```

### 4. Не працюють свайпи або чат (Помилка CSRF або CORS)
- **Причина:** Сайт відкривається через HTTP замість HTTPS, або заблоковано cookie сесії.
- **Рішення:** Переконайтеся, що налаштовано SSL-сертифікат і всі запити автоматично перенаправляються на `https://`.

### 5. Помилка "Call to undefined function imagecreatefromwebp()" або помилка обробки фото
- **Причина:** У PHP не увімкнено розширення `gd` з підтримкою WebP.
- **Рішення:** Увімкніть розширення `php-gd` або `php-imagick` у панелі хостингу (розділ «Select PHP Version» -> «Extensions»).
